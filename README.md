# けいさんドリル

小学校低学年（1〜3年生）向けの、足し算・引き算・掛け算練習アプリです。
タブレットや PC のブラウザで使えます。

## 要件

- **対象**: 小学1〜3年生
- **内容**: かんたん（1桁）・むずかしい（2桁）の足し算・引き算・掛け算
- **端末**: タブレット・PC ブラウザ
- **デザイン**: 大きな文字、ポップなカラーで子どもが使いやすい UI

## 仕様

### レベル

トップ画面でレベルを選ぶ。

| レベル              | 種類   | 数の範囲              |
| ------------------- | ------ | --------------------- |
| かんたん たしざん   | 足し算 | 1〜9 ＋ 1〜9          |
| かんたん ひきざん   | 引き算 | 2〜9 − 1〜(num1−1)    |
| むずかしい たしざん | 足し算 | 10〜99 ＋ 10〜99      |
| むずかしい ひきざん | 引き算 | 20〜99 − 10〜(num1−1) |
| かんたん かけざん   | 掛け算 | 2〜9 × 2〜9           |
| むずかしい かけざん | 掛け算 | 11〜99 × 2〜9         |

- 引き算の答えは必ず 1 以上（負にならない）

### かけざん 九九モード

通常のかけざん（かんたん・むずかしい）とは別に、九九専用の練習モードがある。

- トップ画面の「かけざん 九九」ボタンから入る
- 1の段〜9の段から1つ選択し、同時にモードも選ぶ
  - **じゅんばん**: dan×1, dan×2, ... dan×9 の順で出題
  - **シャッフル**: 同じ9問をランダムな順で出題
- 1セット **9問**（段の全組み合わせ）

### 進行

- 1セット **10問**。正解するたびにカウントアップし、10問正解でクリア
- 不正解の場合は同じ問題を再挑戦
- クリア後は「もどる」でレベル選択に戻れる

### 解答フロー

```
[レベル選択] → [問題表示] → テンキーで入力（1の位から右→左） → [こたえる]
                   ↑正解: バウンス＋緑「せいかい！🎉」→ 1.5秒後に次の問題
                   ↓不正解（かんたんモード）: シェイク＋赤「こたえは ○○！🤔」→ 1.5秒後に再挑戦
                   ↓不正解（筆算モード）:    シェイク＋解き方ヒント表示         → 3秒後に再挑戦
                                              10問正解 (九九は9問) → [クリア画面]
```

#### 筆算モードの不正解時ヒント

不正解のとき、答えを教える代わりに解き方を表示する。

- **繰り上がり（たしざん・かけざん）**: num1 行の上に繰り上がりの数（オレンジ）を表示
- **繰り下がり（ひきざん）**: 貸す桁には減らした数字、借りる桁には「1」をオレンジで表示
- **解答ボックス**: 正しい答えをグリーンで表示

```
┌──────────────────────────────────┐
│  こうやって といてみよう！🔍       │ ← フィードバック
│                                  │
│              1                   │ ← 繰り上がり（オレンジ）
│         4 7                      │
│      ＋  3 8                     │
│      ──────                      │
│       [8] [5]                    │ ← 正解をグリーンで表示
│                                  │
└──────────────────────────────────┘
```

[かけざん 九九] → [段選択] → じゅんばん or シャッフルをタップ → [問題表示]

- **じゅんばん**: dan×1 → dan×2 → … → dan×9 の順で出題
- **シャッフル**: 同じ9問をランダムな順で出題
- 答えは横並びの式 `A × B = [ ]` に数字をそのまま（左から）入力

### スコア表示

- 🌟 **正解数**: `3 / 10 もん` の形式で現在の正解数を表示
- ● **進捗ドット**: 正解済みの問題を塗りつぶして10問分の進捗を可視化
- 🔥 **連続正解**: 2問以上連続で正解すると表示。不正解でリセット
