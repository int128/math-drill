# けいさん れんしゅう

小学校低学年（1〜2年生）向けの、2桁の足し算・引き算練習アプリです。
タブレットや PC のブラウザで使えます。

## 要件

- **対象**: 小学1〜2年生
- **内容**: 2桁の足し算・引き算
- **端末**: タブレット・PC ブラウザ
- **デザイン**: 大きな文字、ポップなカラーで子どもが使いやすい UI

## 仕様

### 問題

| 種類 | num1 | num2（50% ずつランダム） |
|---|---|---|
| 足し算 | 10〜99 | 1〜9（1桁）または 10〜99（2桁） |
| 引き算 | 20〜99 | 1〜9（1桁）または 10〜(num1−1)（2桁） |

- 足し算・引き算はランダムに切り替わる
- 引き算の答えは必ず 1 以上（負にならない）
- 答えは最大 3 桁（198 まで）

### 画面構成

```
┌─────────────────────────────┐
│  けいさん れんしゅう          │
│  🌟 3 もん せいかい！ 🔥 3れんぞく！ │
├─────────────────────────────┤
│                             │
│    23  ＋  45  ＝  □        │
│                             │
├─────────────────────────────┤
│  7   8   9                  │
│  4   5   6                  │
│  1   2   3                  │
│ けす  0  こたえる            │
└─────────────────────────────┘
```

### 解答フロー

```
[問題表示] → テンキーで入力 → [こたえる]
     ↑正解: バウンス＋緑 → 1.5秒後に次の問題
     ↓不正解: シェイク＋赤「ちがうよ！もういちど」→ 1.5秒後に同じ問題で再挑戦
```

- 最大 3 桁まで入力可能
- `けす` で1文字削除
- PC ではキーボード（数字キー・Backspace・Enter）も使用可能

### スコア表示

- 🌟 **正解数**: 正解した問題数を累計表示
- 🔥 **連続正解**: 3問以上連続で正解すると表示。不正解でリセット

## 実装

### 技術スタック

| 項目 | 内容 |
|---|---|
| フレームワーク | React 19 + TypeScript |
| ビルドツール | Vite |
| スタイリング | CSS（ネスト構文）|
| フォント | Google Fonts — M PLUS Rounded 1c |
| リンター | Biome |
| パッケージマネージャ | pnpm |

### 主な状態（State）

| 変数 | 型 | 説明 |
|---|---|---|
| `problem` | `Problem` | 現在の問題（num1, num2, operator, answer） |
| `input` | `string` | ユーザーの入力（最大3文字） |
| `phase` | `'question' \| 'correct' \| 'wrong'` | 現在のフェーズ |
| `correctCount` | `number` | 正解した問題数 |
| `streak` | `number` | 連続正解数 |

### ファイル構成

```
src/
  App.tsx      # アプリ本体（ロジック・UI）
  App.css      # スタイル（ポップデザイン・アニメーション）
  index.css    # ベースリセット
  main.tsx     # エントリポイント
```

## 開発

```bash
pnpm dev      # 開発サーバー起動
pnpm build    # プロダクションビルド
pnpm preview  # ビルド結果をローカルでプレビュー
pnpm check    # Biome でリント・フォーマット
```
